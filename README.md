## Ready to post

Upload `gta6-doc-parody.png` as the first photo in one public X post. Paste `caption-doc.txt` without removing its play code. The user confirmed the X account is public. Keep the post and account public until results are announced.

The illustration is fictional satire, not evidence of an actual bounty win or a promise of income. GTA VI and Rockstar references are used as the subject of the joke. No game screenshots or competitor art are included. The make.fun ghost is a stylized brand reference.

## Reproduce

Node.js 22.18 or later:

    npm install
    npm test
    npm run render

No credentials, wallet keys, model APIs or external images are needed for rendering.
